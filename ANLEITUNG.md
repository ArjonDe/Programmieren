# Java Klausurtrainer – Anleitung

Die komplette App steckt in **einer einzigen Datei: `index.html`** (Code, Design und Inhalte sind darin enthalten).

## Lokal benutzen

`index.html` per Doppelklick im Browser öffnen. Es wird keine Installation und kein Internet benötigt (nur die Schriftart wird online geladen, sonst Systemschrift).

## Auf GitHub Pages veröffentlichen (ohne Ordner, nur Upload im Browser)

1. Auf github.com ein neues Repository anlegen, z. B. `java-klausurtrainer` (Public).
2. Im Repository **Add file → Upload files** wählen und `index.html` hochladen → **Commit changes**.
3. **Settings → Pages → Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**, Ordner **/ (root)** → **Save**
4. Nach 1–2 Minuten ist die Seite erreichbar unter
   `https://<DEIN-NAME>.github.io/java-klausurtrainer/`

## Hinweise

- Der Lernfortschritt wird im Browser gespeichert. Unter *Einstellungen → Sicherung exportieren* kannst du ihn sichern und auf einem anderen Gerät importieren.
- Wenn du `index.html` lokal öffnest und später die GitHub-Version nutzt, ist der Fortschritt getrennt – per Export/Import übertragen.
